# 今日錄製使用說明

雙擊桌面「今日錄製」或資料夾內的 `Start-Recorder.vbs` 開啟工作台。首次使用需登入指定的 Google 帳戶、連接 YouTube 頻道，並允許攝影機與麥克風。

開始前檢查預覽和音量，選好裝置、畫質、方向、文案及上傳設定，再按「開始錄製」。標題與簡介可以留空，伺服器會按實際口播補齊空白欄位；已填內容直接保留。

電腦可先選擇保存資料夾。錄製時縮小視窗仍可繼續，Windows 錄製條顯示時間並提供結束按鈕。不要關閉錄製頁面或讓電腦睡眠。手機請保持 Safari 在前台，勿鎖屏或旋轉。

結束後先保存原片，再選擇只存本機或上傳伺服器。電腦使用指定資料夾或瀏覽器下載；請檢查原片是否真正保存成功。手機可在列表下載，瀏覽器中的恢復副本不應作為唯一備份。

列表分別顯示伺服器與 YouTube 上傳進度。傳送原片期間請保持頁面開啟；可暫停或繼續。原片完整送達後，伺服器會繼續製作。未確認上傳的原片不會自動傳送。

伺服器縮短較長無声停頓，保留短停頓與人聲邊界，並生成逐字稿及需要的文案。YouTube 可見範圍按本次設定發出請求，最終以平台回傳狀態為準；請在 YouTube Studio 核對。

YouTube 確認處理成功後，伺服器清理成片及影音暫存。手機或匯入影片的任務可保留原片，電腦檔案不受此清理影響。失敗任務保留素材以便重試。

首次使用或更換電腦時，先將 `recorder.config.example.json` 複製為 `recorder.config.json`，在 `serverUrl` 填入自己部署的 HTTPS 工作台地址。Chrome 路徑與瀏覽器資料夾留空即可自動偵測與使用目前使用者的獨立目錄。桌面入口需保留整個 `desktop` 資料夾。
