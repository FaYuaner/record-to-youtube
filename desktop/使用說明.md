# 今日录制 · Record to YouTube 使用说明

首次安装，在项目目录执行 `desktop/Install-Local.ps1`，然后双击 `desktop/Start-Recorder.vbs`。桌面快捷方式也可以指向该入口。

默认在本机运行，无需云服务器。入口自动启动本机工作台；摄像头与麦克风权限在浏览器中确认。开始前检查预览和音量，选择画质、方向与原片保存资料夹。

默认处理方式是直接上传原片。标题留空使用录制文件名，简介可为空。自动上传默认开启，可见范围初始为私人；未连接自己的 YouTube 频道时，视频只保留在本机。

连接 YouTube 前，按 [配置指南](../docs/CONFIGURATION.md) 创建自己的 Google 桌面应用 OAuth，配置 `desktop/local.env` 并重启本机服务。点击“连接 Google 账号”完成授权。服务器 Web OAuth 凭据用于远程模式。

录制时不要关闭网页或让电脑睡眠。Windows 录制条显示时间和结束按钮。结束后先保存原片，再按本次设置将视频送入本机队列。完整保存到队列后，可以关闭网页，保持电脑与本机服务运行；下次启动可恢复未完成工作。

录制列表显示保存与 YouTube 上传进度，提供暂停、继续、预览和失败重试。自动上传关闭时，完成准备后可以手动上传。原片和成片保留在本机，重要原片请另行备份。

需要自己的 Skill 剪辑时，配置处理器并选择“自定义剪辑 / Skill”；详见 [自定义剪辑](../docs/CUSTOM_EDITING.md)。内置剪辑另需 FFmpeg、转录模型和相应文案配置。

`recorder.config.json` 可设置 Chrome 路径、浏览器资料目录及 `mode`。本机模式为 `local`；有自己的云端工作台时选择 `remote` 并填写完整 HTTPS `serverUrl`。旧的仅填写 `serverUrl` 的配置仍会使用远程模式。

本机上传队列默认在 `%LOCALAPPDATA%\DaiguiRecorder\data`，服务日志在 `%LOCALAPPDATA%\DaiguiRecorder`。访问链接由桌面入口生成。修改 `local.env` 后需重启服务；可以用任务管理器找到命令行包含此项目 `server\local_runner.py` 的 Python 进程，确认未录制或传输后结束，再启动桌面入口。
