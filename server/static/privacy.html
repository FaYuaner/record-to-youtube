隐私政策

生效日期：2026 年 9 月 11 日

这份政策说明 Daigui Recorder 为你录制、整理和上传影片时，会使用哪些资料，以及你可以如何控制它们。

录制资料保存在你使用的服务实例中，由该实例的管理者负责。

1. 我们处理的资料

  • Google 与 YouTube 授权资料：你授权的 Google 帐户识别资讯、电子邮件、频道名称与频道识别码，以及用于连接 Google 服务的存取和更新授权凭证。工具不会取得你的 Google 密码。
  • 你主动录制的内容：摄影机画面、麦克风声音、原始影片、整理后的成片、语音转录文字，以及处理过程产生的影音档案。
  • 影片与发布资料：你输入或工具产生的标题、描述、可见范围、自动上传设定、工作进度、影片识别码、连结及 YouTube 回传的处理状态。
  • 必要的运作资料：登入工作阶段、上传分片与重试纪录、错误与连线纪录，用于让服务运作、辨识故障及防止重复上传。

2. 摄影机、麦克风与电脑上的保存

你开启工作台并允许浏览器权限后，工具会启用摄影机与麦克风供你预览画面及音量。只有点击开始录制后才会记录影音并计时。录制中会显示画面、计时与录制状态。

你可以选择电脑上的原片储存资料夹。浏览器未取得资料夹写入权限时，会改用浏览器下载。下载是否完成，应以浏览器的下载结果为准。

浏览器会在本机保存你的摄影机与麦克风选择、储存资料夹选择、发布偏好与登入状态所需的资料。原片及是否同意上传的选择可保存在浏览器本机储存区。只有已确认上传的原片会在中断后继续传送；伺服器确认接收完成后，工具会移除此恢复副本。你可透过浏览器的网站资料设定清除这些本机资料；清除前请确认原片已有其他副本。

已授权的浏览器会记住登入状态，使用时自动延长。服务会定期更新 Google 连接并核实频道资料；你可随时登出或解除连接。Google 授权失效或浏览器资料被清除时，需要重新连接。

3. 伺服器与文字处理

录制结束后，工具会先在电脑保存原片，再询问是否上传。你选择「是」后，原片才会经由加密连线传送到你使用的服务实例所配置的伺服器；选择「否」或尚未确认的原片会留在本机，不自动传送。伺服器在本机进行人声辨识、停顿剪辑及语音转文字。

标题或简介留空时，本服务会把语音转录文字传送给本服务配置的文字模型服务，以补齐空白栏位。两项均已填写时，不需要进行文案生成。此步骤不向文字模型服务传送原始音讯或影片。自动产生的文案采用繁体中文；你填写的栏位会直接使用，保留原文。自动上传依开始录制时的设定执行。

录制与转录内容只用于提供你请求的录制、整理与发布功能，不用于本服务自行训练通用人工智慧模型，也不出售给广告商。

4. 与 Google、YouTube 的资料交换

本工具使用 YouTube API Services。你授权后，工具会使用必要权限取得频道资讯、上传你选择的影片与文案，并查询该影片的处理与可见状态。公开、私人与不公开设定将随上传请求传送至 YouTube。

Google 与 YouTube 会依其自身政策处理收到的资料。请阅读 Google 隐私政策 与 YouTube 服务条款。本服务使用从 Google API 取得的资讯时，遵守 Google API Services User Data Policy，包括 Limited Use 要求。

5. 保存、存取与删除

伺服器在处理与上传期间保存原片、成片及处理暂存影音。YouTube 确认影片已成功处理后，工具会自动清理该录制的伺服器影音副本，保留转录、标题、简介和工作记录；失败或结果尚未确认时保留影音供重试。电脑上的原片不受此清理影响。Google 与 YouTube API 回传的相关资料会在 30 天内重新确认或清除。

录制内容的页面与下载要求登入已获准的帐户。服务维护人员可在必要的维护、故障排除或处理你的资料请求时接触相关资料。Google 授权凭证保存在伺服器，供服务依你的授权连接 YouTube。

如需删除保存在本服务的 Google 授权资料、录制或其他个人资料，个人部署时，可管理自己服务器上的资料；使用他人部署的服务时，请联系该实例的管理者，说明要删除的录制或资料范围。电脑上的原片副本由你自行管理；删除本服务中的资料，不会自动删除 YouTube 上已发布的影片。

6. 撤销授权与关闭自动上传

你可以在工作台关闭自动上传，这会套用到后续的新录制。已开始的工作沿用开始时的设定。

你也可以在工具中选择「解除 Google 连结」，或前往 Google 帐户的第三方连结管理页面 撤销授权。在工具中解除连结时，我们会撤销授权并删除相关授权凭证、频道识别资料及 YouTube 回传的上传资料。解除后，工具无法继续以该授权存取 YouTube。登出仅结束目前的登入状态，不等于撤销 Google 授权，也不会停止已经安排的伺服器工作。

撤销授权不会自动删除伺服器上的录制。需要一并删除时，请使用上述联络方式提出请求。

7. 政策更新与联络

服务的资料处理方式若有变更，我们会更新此页与生效日期。若对隐私、授权或资料删除有任何问题，请联系当前服务的管理者。
